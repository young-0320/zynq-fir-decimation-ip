## 5. Velog 연재 ✅ 완료 (2026-08-06, 요구 3편 이상 → 5편 게시)

실제 연재는 후보 주제 나열이 아니라 **시간순 서사**로 재구성했다. 트러블슈팅 3편
(2·3·4편)을 중심에 두되, 앞에 bring-up(1편)을, 뒤에 결산(5편)을 붙여 프로젝트 전체가
하나의 흐름으로 읽히게 했다. ASIC 타겟 종속성은 독립 편 대신 5편의 핵심 절로 넣었다.

- [X] 1편: Block Design부터 비트스트림·XSA까지
- [X] 2편: DDR byte[3] 오염 — JTAG ELF 로딩에 걸린 16일 (재료: log 21~27)
- [X] 3편: 끝나지 않는 MM2S — AXI DMA 1바이트 초과 (재료: log 31/32)
- [X] 4편: 동작하는 회로의 버그 4개 (재료: log 41~44)
- [X] 5편: 숫자로 쓰는 결산 — Fmax 스윕·CPU 대비·전력 실측·ASIC 교차 검증
  (재료: log 37/39/40/46/47/49 + summary 4종)
- [X] 링크 확보 → README 한/영 "개발 연재 (Velog)" 섹션에 5편 전부 반영

5편 작성 중 확인된 사항 (원고에 반영, 근거는 아래 문서):

- N=43 선정 근거를 저지대역 worst-case 기준으로 재서술 (log 07 — 39/41탭은 25MHz
  한 점만 보면 통과처럼 보이나 전 구간 worst-case에서 미달)
- 시나리오 1-2의 45MHz 실측 −64.5dB는 필터 성능이 아니라 **측정계의 관측 하한**
  (계수 응답 |H(45MHz)| = 77.2dB, float64 재현에서도 동일 수준 → 양자화 아님)
- 25MHz만 −6.02dB 정규화 오프셋이 상쇄됨 (출력 Nyquist bin은 크기가 2배로 잡힘)
- CPU 221.0µs는 대표값이 아니라 최종 차트 생성 라운드의 값이며 관찰 구간(170~300µs)의
  높은 쪽 — 배속을 2.0~3.5배 구간으로 병기 (log 49)
